Offline Earth options

Plain examples of the available renderers, views, time controls and inputs. Extract the ZIP and keep the outputs/ folder beside this file. No server is needed.

Unless noted, examples use the same two illustrative LEO paths and a stationary ground site, with markers at 4800 seconds. Static globe and Canvas camera: 65° W, 25° N. Static globe extent: 1.25 Earth radii. Plotly uses its default 3D perspective.

3. Input and trajectory options

  • JSON: sample-ecef.json. A single trajectory object or a wrapper with trajectories; per-track name, color, optional epoch and samples. Explicit metadata must be ECEF, metres, seconds. The spelling metres is the existing serialized token; coordinates are meters. Missing metadata is accepted; conflicting metadata is rejected.
  • CSV: sample-ecef.csv. Columns time_s,x_m,y_m,z_m, plus optional name. Grouped by name, or filename stem if absent. CSV does not import custom colors or epochs, so it will not reproduce JSON's track colors.
  • Python arrays/generators: EcefTrajectory.from_arrays(name, time_s, xyz_m, color="#RRGGBB", epoch_utc=None). Matching lengths, exactly three coordinates per row, finite values, at least one sample, strictly increasing times. Input is copied to immutable validated samples.
  • No trajectories: omit --ecef or pass []. All Earth renderers work; Canvas hides the timeline. Timeseries requires data.
  • Multiple tracks/files: repeat --ecef FILE or combine loaded lists. Unified rendering requires all epochs to represent the same instant, or all to be omitted. Explicit epochs must be timezone-aware. Times are elapsed seconds, not assumed Unix timestamps.
  • Altitude: high-altitude fixed point. ECEF input can describe different heights and motions; no orbit propagation is performed. Ground maps discard altitude, globe/Canvas preserve it in projection, Plotly shows true 3D coordinates.
  • Longitude/latitude tracks and stations: direct APIs accept raw tracks separately from ECEF; SVG also accepts stations. The raw SVG example includes both; its caller must split raw tracks at the dateline. ECEF ground tracks are split automatically.

4. CLI options and defaults

The CLI defaults to SVG; RenderSpec() defaults to the Matplotlib map. Choose the output extension explicitly when changing renderer.

CLI optionDefault / accepted value
positional outputworld.svg. Local destination path.
--renderersvg; choices: svg, map, globe, interactive, canvas, timeseries.
--modecombined; imagery, political, combined. See backend differences above.
--ecefNo input files by default. Repeatable local CSV or JSON path.
--at-sNone; finite elapsed seconds. See differing renderer defaults above.
--center-lon-deg−30. Finite longitude in degrees; not limited to ±180.
--center-lat-deg22. Latitude from −90 to 90 degrees.
--extent-earth-radii1.35. Finite value at least 1.05.

Shared arguments are validated even for backends that ignore them. There is no CLI --renderer plotly, and no Python backend="interactive" alias.

offline-earth earth.html --renderer canvas --mode combined --ecef sample-ecef.json --at-s 4800

offline-earth globe.png --renderer globe --mode political --ecef sample-ecef.json --center-lon-deg -65 --center-lat-deg 25 --extent-earth-radii 1.25

from offline_earth.visualize import RenderSpec, render_ecef
from offline_earth.timeseries import matplotlib_ecef_timeseries

tracks = read_trajectories("sample-ecef.json")
render_ecef(tracks, "globe.png", spec=RenderSpec(
    backend="globe", mode="combined", at_s=4800,
    center_lon_deg=-65, center_lat_deg=25, extent_earth_radii=1.25))
matplotlib_ecef_timeseries("xyz-meters.png", tracks, unit="m")

6. Dependencies and verification limits

  • SVG and Canvas generation: core wheel only, no third-party runtime dependencies.
  • Install the [plot] extra from wheels for map, globe and timeseries. It includes NumPy, Matplotlib and Pillow; timeseries does not directly use Pillow.
  • Plotly: NumPy, Pillow and Plotly wheels. JavaScript is embedded.
  • Viewing generated files does not require Python. Browser binaries are separate installed software and are never downloaded by the library.

Static outputs and local files are generated and checked in Python. Browser interactions, WebGL rendering and this HTML layout remain unverified in the current execution environment. The PNGs are static Matplotlib output, not browser screenshots.

The paths are illustrative, not orbit propagation. ECEF is Earth-fixed; no ECI conversion, terrain or high-precision limb clipping. Borders are simplified. NASA imagery is July 2004, not a live feed. Canvas/Matplotlib globe appearance is spherical; ECEF transforms use WGS84 and Plotly uses an ellipsoid. Asset terms and code-license status are unchanged. No merge, release or PR closure is performed.
